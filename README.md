#NexusMind Personality Decoder
A machine learning web app that predicts your personality (Introvert, Extrovert, Ambivert or Omnivert) based on your daily habits and behavioural patterns.
Built with Python, Scikit-Learn and Streamlit.
**Personality types:** Introvert, Extrovert, Ambivert, Omnivert.
**Model Accuracy:** 87.0%
